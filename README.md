# Introduction-to-machine-learning---Final-Project---TM-NZS-
Final project for the Introduction to Machine Learning course created by Téglás Máté (FWQPSP) and Németh Zsombor (HV911G)

Our chosen project is project number 20. Gender and Age prediction based on images

In this project, we aim to build a machine learning model that can predict a person's gender and age group based on facial images.

The task consists of two main parts:
1. Gender classification: determining whether the person in the image is male or female.
2. Age group classification: categorizing the person into one of several age groups (e.g. young, middle-aged, elderly).

We will use a dataset of labeled face images and train a Convolutional Neural Network (CNN) to learn relevant visual features. The model will be trained, validated, and tested on separate subsets of the data.

The final goal is to evaluate the performance of the model using appropriate metrics such as accuracy and confusion matrices, and to analyze its strengths and limitations.
